 # 🍽️ Apetitoso Sabor

### Website de Restaurante | Projeto Demonstrativo

O **Apetitoso Sabor** é um projeto de desenvolvimento web que simula a interface de um restaurante fictício, desenvolvido com **HTML5, CSS3 e JavaScript**.

O objetivo é demonstrar habilidades em criação de interfaces modernas, responsividade, manipulação do DOM e implementação de funcionalidades interativas.

### ✨ Funcionalidades

- 📱 Layout responsivo para diferentes tamanhos de tela.
- 🍔 Cardápio dinâmico com produtos, descrições e preços.
- 🔎 Filtros por categorias de alimentos.
- 🛒 Simulação de carrinho com contador de itens.
- 🔔 Notificações interativas ao adicionar produtos.
- 🎨 Animações e efeitos visuais com CSS.
- 🔢 Contadores animados na seção de apresentação.
- 🌐 Publicação do projeto na Vercel.

### 📂 Estrutura do projeto

```text
PORTIFOLIO/
├── index.html
├── style.css
└── script.js
```

**index.html:** estrutura e conteúdo da página.

**style.css:** identidade visual, layout, animações e responsividade.

**script.js:** cardápio dinâmico, filtros, carrinho demonstrativo e interatividade.

### 🛠️ Como executar localmente

1. Clone ou baixe este repositório.
2. Abra a pasta `PORTIFOLIO`.
3. Abra o arquivo `index.html` em um navegador.

O projeto utiliza HTML, CSS e JavaScript, sem necessidade de instalar dependências.

### 📌 Sobre o projeto

Este website foi desenvolvido exclusivamente para fins de estudo, demonstração técnica e composição de portfólio.

**O restaurante é fictício.** Os preços, horários, dados comerciais e funcionalidades de pedidos são ilustrativos. Não há processamento de pagamentos nem atendimento comercial real.
